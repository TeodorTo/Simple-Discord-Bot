# 🎓 Simple Discord Bot — Бот за училищен/учителски сървър

Този проект представлява **умен Discord бот**, предназначен за училищни или учебни сървъри.
Той позволява:

* автоматично разпознаване на учители и ученици,
* създаване на частни канали,
* автоматично добавяне на роли чрез покани,
* автоматично създаване на временни гласови канали,
* и дори настройване на псевдоним (име и фамилия) на всеки нов член.

---

## 🚀 Функционалности

### 👩‍🏫 Управление на учители

* Команда: `!add-teacher @учител ИмеНаРоля`
* Добавя учител в системата и създава съответна роля за учениците му.
* Данните се съхраняват в `teachers.json`.

---

### 🔗 Генериране на покани за конкретен учител

* Команда: `!generate-invite @учител`
* Създава уникален Discord линк (invite), който при използване автоматично дава ролята, асоциирана с този учител.
* Информацията се записва в `trackedInvites.json`.

---

### 💬 Частни чатове между ученик и учител

* Команда: `!create-private-channels`
* Създава частни текстови канали, достъпни само за дадения учител, ученика и бота.
* Каналът се именува според псевдонима на ученика.

---

### 🔊 Join-to-Create VC

* Команда: `!setup-vc`
* Създава специален гласов канал „➕ Join to Create VC“.
* При влизане в него, ботът автоматично създава временен личен VC канал за потребителя.
* Когато каналът се изпразни, ботът го изтрива.

---

### 🙋‍♂️ Автоматично приветствие и псевдоним

* При влизане на нов член, ботът:

  1. Изпраща лично съобщение (DM).
  2. Моли потребителя да въведе име и фамилия.
  3. Автоматично задава псевдоним (nickname) в сървъра.

## ⚙️ Изисквания

### 🧩 Задължителни:

* [Node.js](https://nodejs.org/) (версия 18 или по-нова)
* [Discord Developer Portal](https://discord.com/developers/applications)

  * Създай приложение и бот.
  * Копирай **Bot Token**.
  * Дай му следните **права**:

    * `Manage Nicknames`
    * `Manage Channels`
    * `Send Messages`
    * `Read Messages`
    * `Create Instant Invite`
    * `Move Members`

## 🛠️ Инсталация

1. **Клонирай хранилището**

   ```bash
   git clone https://github.com/<твоето_потребителско_име>/Simple-Discord-Bot.git
   cd Simple-Discord-Bot
   ```

2. **Инсталирай нужните пакети**

   ```bash
   npm install
   ```

3. **Създай `.env` файл** в основната папка на проекта:

   ```
   DISCORD_TOKEN=твоят_реален_бот_токен
   ```

4. **Увери се, че присъстваш тези файлове:**

   ```
   teachers.json
   trackedInvites.json
   ```

   Ако липсват — създай празни такива:

   ```json
   {
     "teachers": []
   }
   ```

   ```json
   {}
   ```

## 🔒 Настройки за права

Ролята на бота в сървъра трябва да бъде **над ролите на потребителите**, чиито псевдоними иска да променя.
В противен случай ще получиш грешка:

```
DiscordAPIError[50013]: Missing Permissions
```

## 💡 Полезни съвети

* Ако ботът не получава лични съобщения, увери се, че в **Privacy Settings** на потребителя е разрешено:

  > “Allow direct messages from server members”

* Ако не може да променя псевдоними:

  > Премести ролята на бота най-горе в списъка с роли.
